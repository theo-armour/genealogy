# gedcom agenda

## GEDCOM Viewer

https://pewu.github.io/topola-viewer/

This viewer allows you to visualize GEDCOM files interactively. You can upload your GEDCOM file and explore the family tree structure with ease. It's wonderful for genealogists who want to analyze and understand family connections in a dynamic way.

Nonetheless, I would like to improve it. One potential enhancement could be adding more customization options for the visualization, such as different tree layouts, color coding for different family branches, and the ability to highlight specific individuals or relationships. Additionally, integrating more detailed information from the GEDCOM file directly into the viewer could make it even more useful for genealogical research.

## Potential Improvements

* Linking to the biographies in this genealogy repository
* Displaying pictures or media associated with individuals
* Different tree layouts (e.g., vertical, horizontal, radial)
* Color coding for different family branches
* Highlighting specific individuals or relationships
* Displaying detailed information from the GEDCOM file
* Enhanced search and filtering capabilities within the family tree
* Exporting the visualized tree as an image or PDF for sharing and documentation
