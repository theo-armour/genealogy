## Discrepancies vs. README

* **Middle name spelling:** The `Names and Spellings` section uses the German spelling `Benedikt` (`Maximilian Carl Benedikt Graf von Nieroth`), whereas the README uses `Benedict`.
* **Father's given names:** The primary Genealogy entry lists `Reinhold Johan Evstafyevich Nieroth` (without `Gustaf`), whereas both the `Alternate record` and the README include `Gustaf` (`Gustaf Reinhold Johan von Nieroth`).
* **Sibling's given-name order:** The `Alternate record` lists `Wilhelm Julius Alexander Nieroth`, whereas the README and primary Genealogy entry list `Alexander Wilhelm Julius`.
